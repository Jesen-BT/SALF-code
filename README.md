# SALF-code
Subspace Adaptive Learning Framework for Trapezoidal Data Streams with Concept Drift

Environment Requirements
This project is implemented in Python 3.10
Core Dependencies：
numpy              1.23.5
scipy              1.15.3
pandas             2.3.2
scikit-learn       1.1.3
scikit-multiflow   0.5.3
matplotlib         3.10.6
seaborn            0.13.2
statsmodels        0.14.5
scikit-posthocs    0.11.4
joblib             1.5.2


Due to file size limitations, the Sensor and Covertype (Covtype) datasets are not included in the data/ directory of this repository.
Readers can download these datasets from the following official sources:

Sensor Dataset：UCI Machine Learning Repository

Covertype Dataset：MOA Dataset Collection

After downloading, please place the processed data files into the data/ directory following the same format as the other datasets used in this project.
